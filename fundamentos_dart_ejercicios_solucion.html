Ejercicio 1: Estadísticas de calificaciones

Escribe una función que reciba una lista de calificaciones (enteros entre 0 y 10) y devuelva un mapa con: "promedio de notas", "Nº de aprobados" (≥5) y "Nota máxima". Si la lista está vacía, devuelve valores 0.

Solución:

Conceptos aplicados: listas, funciones, operadores de colección (where, reduce), nulabilidad, mapas.

Esta línea define una función en Dart. Vamos a desglosar cada parte para entender su significado y propósito.

La función analizarCalificaciones indica que devuelve un mapa (diccionario) donde:

  • Las claves son siempre de tipo String (ej. "promedio", "aprobados").
  • Los valores pueden ser de cualquier tipo (int, double, null, etc.), gracias a la palabra clave dynamic.

Se usa dynamic aquí porque el mapa mezcla tipos distintos: promedio es un double, aprobados es un int, y maxima puede ser int o null.

No te preocuopes si no hubieras sido capaz de hacerlo así. Yo tampoco. Conocer todas las funciones asociadas a los objetos de lenguaje es prácticamente imposible y más si estamos empezando. Lo importante es entender la lógica y el flujo del programa.

Alternativa más segura (opcional)

En lugar de usar Map<String, dynamic>, puedes crear una clase para mejorar la seguridad de tipos: 

class ReporteCalificaciones {
  final double promedio;
  final int aprobados;
  final int? maxima;
  ReporteCalificaciones(this.promedio, this.aprobados, this.maxima);
}

Esto evita el uso de dynamic y permite al compilador detectar errores antes de ejecutar el programa.

Ejercicio 2: Gestión de una biblioteca

Crea las clases Libro y Biblioteca. La biblioteca debe permitir: añadir libros y obtener una lista de libros disponibles.

Solución:

class Libro {
  final String titulo;
  final String autor;
  final int anio;

  Libro({
    required this.titulo,
    required this.autor,
    required this.anio,
  });

  @override
  String toString() => '"$titulo" de $autor ($anio)';
}

class Biblioteca {
  final String nombre;
  final List _libros = [];

  Biblioteca({required this.nombre});

  void agregarLibro(Libro libro) {
    _libros.add(libro);
    print('Libro agregado: $libro');
  }

  List get librosDisponibles => List.unmodifiable(_libros);

  void mostrarLibros() {
    if (_libros.isEmpty) {
      print('No hay libros disponibles en "$nombre".');
      return;
    }
    print('\n📚 Libros disponibles en "$nombre":');
    for (var i = 0; i < _libros.length; i++) {
      print('  ${i + 1}. ${_libros[i]}');
    }
  }
}

void main() {
  final biblioteca = Biblioteca(nombre: 'Biblioteca Central');

  final libros = [
    Libro(titulo: 'Cien Años de Soledad', autor: 'Gabriel García Márquez', anio: 1967),
    Libro(titulo: 'Don Quijote de la Mancha', autor: 'Miguel de Cervantes', anio: 1605),
    Libro(titulo: 'La Sombra del Viento', autor: 'Carlos Ruiz Zafón', anio: 2001),
  ];

  for (var libro in libros) {
    biblioteca.agregarLibro(libro);
  }

  biblioteca.mostrarLibros();

  print('\nTotal de libros disponibles: ${biblioteca.librosDisponibles.length}');
}

Conceptos aplicados: clases, encapsulamiento (propiedad privada con _), getters, métodos, colecciones, nulabilidad.
