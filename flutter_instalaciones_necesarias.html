Instalaciones en el equipo

  1. Git ↗

    Sistema de control de versiones. Esencial para colaborar y guardar el historial de tu código.

    Abre una terminal y teclea:

    git --version
    Si te devuelve un número de versión, ya lo tienes instalado. Si no, instálalo desde el enlace anterior. Después, configura tu nombre y correo: 

    git config --global user.name "Tu nombre"
git config --global user.email "Tu correo"
  2. Crear cuenta en GitHub ↗

    Plataforma para alojar y compartir tu código. Es el estándar de la industria para desarrollo colaborativo.

  3. VSCode - Visual Studio Code ↗

    Editor de código ligero, rápido y altamente personalizable. Ideal para desarrollar con Flutter y Dart.

  4. Postman ↗

    Herramienta para probar APIs REST. Muy útil si tu app se comunica con un backend.

  5. Android Studio ↗

    Entorno oficial para desarrollar apps Android. Flutter lo necesita para compilar y ejecutar en dispositivos Android.

  6. Sólo Mac: xCode ↗

    Herramienta oficial de Apple para desarrollar apps iOS. Necesaria para compilar y probar en iPhone o iPad.

  7. Flutter SDK ↗

    El kit de desarrollo de Flutter. Incluye todo lo necesario para construir apps multiplataforma desde una sola base de código. En esta instalación en la carpeta bin se encuentran las herramientas flutter y también de Dart.

  8. NodeJS ↗

    Entorno de ejecución JavaScript. Requerido para algunas herramientas de desarrollo modernas y dependencias de frontend.

  9. Docker Desktop ↗

    Plataforma para crear, desplegar y ejecutar aplicaciones en contenedores. Útil para simular entornos de producción.

  10. Table Plus ↗ ← Visor de base de datos

    Cliente moderno y visual para administrar bases de datos (PostgreSQL, MySQL, SQLite, etc.).

Confguraciones en VSCode:

  • En VStudio Code -> Menú View -> Command Palette (Command + Shift + P) buscamos: Open user settings (JSON) y añadimos este fragmento de configuración: 

    "[dart]": {
    "editor.formatOnSave": false,
    "editor.formatOnType": true,
    "editor.selectionHighlight": false,
    "editor.suggest.snippetsPreventQuickSuggestions": false,
    "editor.suggestSelection": "first",
    "editor.tabCompletion": "onlySnippets",
    "editor.wordBasedSuggestions": false
}
  • Iconos: Material Icon Theme ↗

    Iconos temáticos para archivos y carpetas en VSCode. Mejora la legibilidad del explorador de archivos.
