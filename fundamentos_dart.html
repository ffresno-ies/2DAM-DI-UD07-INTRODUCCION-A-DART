1. Introducción a Dart

Dart es un lenguaje de programación moderno, desarrollado por Google, fuertemente tipado pero con soporte para inferencia de tipos. Se utiliza sobre todo en Flutter para desarrollo multiplataforma, aunque también sirve para backend y aplicaciones de consola.

Lenguaje Optimizado para UI: Dart es un lenguaje del lado del cliente que está optimizado para interfaces de usuario (UIs). Desde su concepción, todo en Dart fue pensado para permitir la creación y potenciar a Flutter

Debido a que tanto Dart como Flutter fueron creados por Google, se garantiza una excelente compatibilidad a futuro. Dart no incluirá cambios importantes (Breaking changes) que destruyan la funcionalidad de Flutter, ya que fue concebido para darle potencial a este framework

Dart (a través de Flutter) permite el despliegue a una amplia gama de plataformas, incluyendo móvil, web, escritorio (Windows, Linux y Mac OS X), e incluso en sistemas embebidos (como las pantallas de los automóviles, un ejemplo mencionado es Toyota)

Características principales:

  • Sintaxis similar a C/Java.
  • Orientado a objetos.
  • Soporte para programación asíncrona (async / await).
  • Tipado estático pero flexible (inferencia de tipos).
  • Soporte para nulabilidad segura (null safety).

1.1 ¿Por qué aprender Dart para Flutter?

Antes de comenzar a aprender Flutter, es imprescindible dominar primero el lenguaje Dart. Flutter utiliza Dart para definir toda la lógica, las estructuras de datos, la gestión del estado y gran parte del comportamiento interno de una aplicación.

Aunque Flutter incorpora su propio conjunto de widgets y herramientas para construir interfaces, el código que los hace funcionar sigue siendo Dart. Por eso es fundamental saber diferenciar qué pertenece al lenguaje y qué forma parte del framework.

Los elementos que se describen en este manual —variables, tipos de datos, funciones, clases, constantes y demás fundamentos— son esenciales para comprender cómo opera Flutter por dentro y para poder escribir aplicaciones eficientes, limpias y mantenibles.

Sin una base sólida en Dart, aprender Flutter se vuelve confuso y limitado; con ella, en cambio, se potencia el aprendizaje y se facilita el desarrollo profesional.

3. Variables y tipos de datos

En Dart, una variable es un espacio en memoria donde se almacena un valor. El lenguaje permite declarar variables de diferentes maneras según el nivel de estrictitud y el momento en que se conoce el tipo del dato.

2.1 Declaración con tipo explícito

Dart permite especificar directamente el tipo de dato que contendrá la variable. Esto mejora la claridad del código y evita errores.

int edad = 20;
  • int indica que la variable solo podrá almacenar números enteros.
  • El tipo explícito ayuda al compilador a detectar asignaciones incorrectas.

2.2 Declaración con inferencia de tipo (var)

Cuando se utiliza var, Dart determina automáticamente el tipo de la variable a partir del valor asignado.

var nombre = "Ana";
  • El compilador infiere que nombre es un String.
  • Una vez inferido, el tipo no puede cambiar.

2.3 Constantes: const y final

Dart ofrece dos palabras clave para definir valores que no cambiarán:

const – Constantes en tiempo de compilación

const double pi = 3.1416;
  • El valor debe ser conocido antes de ejecutar el programa.
  • Útil para valores completamente inmutables.

final – Constantes en tiempo de ejecución

final fecha = DateTime.now();
  • Su valor se asigna una sola vez, pero puede calcularse durante la ejecución.
  • Ideal para valores dinámicos pero inmutables.

2.4 Ejemplo completo

void main() {
  // Declaración con tipo explícito
  int edad = 20;
  // Declaración con inferencia de tipo
  var nombre = "Ana";
  // Constantes
  const double pi = 3.1416; // tiempo de compilación
  final fecha = DateTime.now(); // tiempo de ejecución
  print("Edad: $edad, Nombre: $nombre, Pi: $pi, Fecha: $fecha");
}
Nota:
  • var → infiere el tipo.
  • const → valor fijo en compilación.
  • final → valor fijo en tiempo de ejecución.

4. Entrada de Datos (desde consola)

En Dart, para leer datos desde la consola (entrada estándar), se utiliza la librería dart:io, específicamente la propiedad stdin.

Lectura básica de texto

El método readLineSync() lee una línea completa introducida por el usuario y devuelve un String? (puede ser null si no hay datos). 

import 'dart:io';

void main() {
  print("Introduce tu nombre:");
  String? nombre = stdin.readLineSync();
  print("Hola, \$nombre!");
}

Conversión a otros tipos

Como readLineSync() devuelve un String?, es común convertirlo a otros tipos como int, double, etc. Es importante manejar posibles errores con try-catch. 

import 'dart:io';

void main() {
  print("Introduce tu edad:");
  String? input = stdin.readLineSync();
  
  if (input != null) {
    try {
      int edad = int.parse(input.trim());
      print("Tienes \$edad años.");
    } catch (e) {
      print("Entrada no válida. Por favor, introduce un número entero.");
    }
  }
}

Notas importantes

  • readLineSync() devuelve null si se alcanza el final del flujo de entrada (por ejemplo, al presionar Ctrl+D en Unix o Ctrl+Z en Windows).
  • Siempre es buena práctica verificar que el valor no sea null antes de usarlo.
  • Usa .trim() para eliminar espacios innecesarios al principio o al final de la entrada.
  • La interpolación de cadenas con \$variable facilita la inclusión de valores en mensajes.

5. Estructuras Condicionales

Las estructuras condicionales permiten ejecutar diferentes bloques de código según se cumpla o no una condición. Dart admite las instrucciones if, else if, else, y el operador ternario para expresiones condicionales.

Condicional if-else

La estructura básica evalúa una expresión booleana. Si es true, se ejecuta el bloque if; de lo contrario, se ejecuta el bloque else (si está presente). 

void main() {
  int edad = 18;
  if (edad >= 18) {
    print("Eres mayor de edad.");
  } else {
    print("Eres menor de edad.");
  }
}

Operador ternario

El operador ternario es una forma concisa de asignar un valor basado en una condición. Sintaxis: condición ? valorSiTrue : valorSiFalse. 

// Operador ternario
String permiso = edad >= 18 ? "Permitido" : "Denegado";
print("Acceso: \$permiso");

Múltiples condiciones con else if

Puedes encadenar varias condiciones para manejar múltiples casos. 

int calificacion = 85;

if (calificacion >= 90) {
  print("Excelente");
} else if (calificacion >= 70) {
  print("Aprobado");
} else if (calificacion >= 50) {
  print("Aprobado con dificultad");
} else {
  print("Suspenso");
}

Condiciones con operadores lógicos

Puedes combinar condiciones usando && (AND), || (OR) y ! (NOT). 

int edad = 20;
bool tieneLicencia = true;

if (edad >= 18 && tieneLicencia) {
  print("Puede conducir legalmente.");
} else if (edad >= 18 && !tieneLicencia) {
  print("Es mayor de edad, pero necesita licencia.");
} else {
  print("No puede conducir.");
}

Notas importantes

  • En Dart, solo los valores booleanos (true o false) son válidos en condiciones. No se consideran "falsos" valores como 0, "" o null (a diferencia de otros lenguajes).
  • Si omites las llaves {} en un bloque if, solo se ejecutará la siguiente línea. Por legibilidad y seguridad, se recomienda siempre usar llaves.
  • El operador ternario debe tener ambos lados definidos; no se puede omitir la parte : valorSiFalse.

6. Bucles y Estructuras de Control

Dart ofrece varias estructuras para controlar el flujo de ejecución: bucles para repetir tareas (for, while, do-while) y la instrucción switch para tomar decisiones múltiples basadas en un valor.

Bucle for

Ideal para iterar un número conocido de veces. La sintaxis clásica incluye inicialización, condición y actualización. 

for (int i = 0; i < 5; i++) {
  print("Iteración \$i");
}

Dart también soporta el bucle for-in para recorrer colecciones como listas. 

List<String> frutas = ['manzana', 'plátano', 'naranja'];
for (String fruta in frutas) {
  print("Me gusta la \$fruta");
}

Bucle while

Ejecuta un bloque de código mientras una condición sea true. La condición se evalúa antes de cada iteración. 

int contador = 3;
while (contador > 0) {
  print("Cuenta regresiva: \$contador");
  contador--;
}

El bucle do-while es similar, pero garantiza que el bloque se ejecute al menos una vez, ya que la condición se evalúa al final. 

int intentos = 0;
do {
  print("Intento número \${intentos + 1}");
  intentos++;
} while (intentos < 3);

Instrucción switch

Permite comparar un valor contra múltiples casos. Dart requiere que los casos sean constantes (como literales o valores const). 

  //Para el test1
  String dia = "lunes";
  //Parea el test2
  String dia = "sábado";

  switch (dia) {
    case "lunes":
      print("Inicio de la semana");
      break;
    case "viernes":
      print("Fin de la semana laboral");
      break;
    // Usar '|' para multiples valores
    case "sábado" | "domingo": 
      print("Fin de semana");
      break;
    default:
      print("Día entre semana");
  }

Notas importantes

  • En Dart, switch no permite "caída" (fall-through) entre casos, excepto si el caso está vacío (como case "sábado": seguido inmediatamente de case "domingo":).
  • Siempre incluye break, return o continue al final de un caso no vacío; de lo contrario, el código no compilará.
  • Los bucles for-in son ideales para colecciones, pero no permiten modificar la colección durante la iteración.
  • Usa while cuando no sepas cuántas iteraciones necesitarás (por ejemplo, lectura de datos hasta que el usuario escriba "salir").

7. Funciones

Las funciones en Dart son bloques de código reutilizables que pueden recibir parámetros y devolver un valor. Dart es un lenguaje con tipado estático, por lo que se recomienda especificar los tipos de los parámetros y del valor de retorno.

Función básica con retorno

Una función típica declara el tipo de retorno, nombre, parámetros y cuerpo con llaves. 

// Función con parámetros y retorno
int sumar(int a, int b) {
  return a + b;
}

print(sumar(7,3));

Funciones flecha (arrow functions)

Cuando el cuerpo de la función es una sola expresión, puedes usar la sintaxis de flecha (=>). 

// Función flecha (equivalente a la anterior)
  int multiplicar(int a, int b) => a * b;
  print(multiplicar(7,3));

Parámetros opcionales

Dart admite dos tipos de parámetros opcionales: nombrados y posicionales.

Parámetros nombrados (entre llaves {})

  void saludar({String nombre = "Invitado", int edad = 0}) {
    print("Hola $nombre, tienes $edad años.");
  }

  // Uso
  saludar(nombre: "Ana", edad: 25);
  saludar(nombre: "Luis"); // edad usará valor por defecto
  saludar(); // usa ambos valores por defecto

Parámetros posicionales opcionales (entre corchetes [])

String formatearNombre(String nombre, [String? apellido]) {
  if (apellido != null) {
    return "\$nombre \$apellido";
  }
  return nombre;
}

// Uso
print(formatearNombre("María"));           // "María"
print(formatearNombre("Carlos", "Ruiz"));  // "Carlos Ruiz"

Funciones como ciudadanos de primera clase

En Dart, las funciones se pueden asignar a variables, pasar como argumentos o devolver desde otras funciones. 

int operacion(int a, int b, Function(int, int) fn) {
  return fn(a, b);
}

int restar(int x, int y) => x - y;

void main() {
  int resultado = operacion(10, 3, restar);
  print(resultado); // 7
}

Funciones anónimas

Útiles para callbacks o funciones de corta duración. No tienen nombre. 

void main() {
  List<int> numeros = [1, 2, 3];
  numeros.forEach((n) => print(n * 2)); // 2, 4, 6
}

Notas importantes

  • Si una función no devuelve un valor, se declara con void.
  • Los parámetros nombrados son opcionales por defecto, pero puedes hacerlos obligatorios usando required (desde Dart 2.12+ con nulabilidad).
  • Las funciones flecha no usan llaves ni la palabra return; la expresión se devuelve automáticamente.
  • Puedes combinar parámetros obligatorios, posicionales opcionales y nombrados, pero deben aparecer en este orden: func(a, [b], {c}).

8. Colecciones

Las colecciones en Dart te permiten agrupar y manipular múltiples valores de forma eficiente.

8.1. List (listas)

Una List en Dart es una colección ordenada de elementos, a los que se accede por su índice numérico (empezando en 0). Las listas pueden contener elementos de cualquier tipo, y su tamaño puede ser fijo o dinámico.

Creación y acceso básico

Puedes crear una lista con corchetes [] o con el constructor List.filled(). El acceso se hace con [índice], y si el índice no existe, lanzará una excepción en tiempo de ejecución. 

void main() {
  List<String> meses = [
    "Enero", "Febrero", "Marzo", "Abril", "Mayo", "Junio",
    "Julio", "Agosto", "Septiembre", "Octubre", "Noviembre", "Diciembre"
  ];

  // Acceso por índice
  print(meses[0]);      // "Enero"
  print(meses[11]);     // "Diciembre"

  // Modificación
  meses[0] = "ENE";
  print(meses[0]);      // "ENE"

  // Tamaño de la lista
  print("Total de meses: \${meses.length}"); // 12
}

Listas dinámicas vs. fijas

Por defecto, las listas en Dart son dinámicas (puedes añadir o eliminar elementos). Si necesitas una lista de tamaño fijo, usa List.filled(). 

// Lista dinámica (tamaño variable)
List<int> numeros = [1, 2, 3];
numeros.add(4); // OK
print(numeros); // [1, 2, 3, 4]

// Lista fija (tamaño inmutable)
List<String> colores = List.filled(3, "blanco");
// colores.add("rojo"); // ❌ Error en tiempo de ejecución
colores[0] = "rojo"; // ✅ Permitido (solo reemplazo)
print(colores); // [rojo, blanco, blanco]

Métodos comunes para manipular listas

Dart ofrece muchos métodos útiles para trabajar con listas. 

List<String> meses = ["Enero", "Febrero", "Marzo"];

// Añadir elementos
meses.add("Abril");
meses.addAll(["Mayo", "Junio"]);

// Eliminar por valor o índice
meses.remove("Febrero");         // elimina la primera coincidencia
meses.removeAt(0);               // elimina "Enero"

// Verificar contenido
if (meses.contains("Marzo")) {
  print("¡Marzo está en la lista!");
}

// Iterar
for (String mes in meses) {
  print(mes);
}

// También puedes usar forEach
meses.forEach((mes) => print(mes));

Listas y nulabilidad

En Dart con nul-safety, el acceso a un índice inválido no devuelve null, sino que lanza una excepción. Siempre valida el rango antes de acceder. 

List<String> meses = ["Enero", "Febrero"];

// ❌ Peligroso: podría lanzar RangeError
// print(meses[5]);

// ✅ Seguro: verificar el rango
if (5 < meses.length) {
  print(meses[5]);
} else {
  print("Índice fuera de rango");
}

Notas importantes

  • Todas las listas en Dart implementan la interfaz List y son indexadas desde 0.
  • Las listas literales con [] son dinámicas por defecto.
  • Para crear una lista vacía con tipo explícito, escribe: List<String> frutas = []; (sin esto, Dart podría inferirla como List<Object> en contextos ambiguos).
  • Puedes usar first, last, isEmpty, isNotEmpty, etc., para operaciones comunes.
  • Los elementos de una lista pueden ser de tipos distintos si usas List<Object> o List<dynamic>, pero se recomienda tipar fuertemente.

8.2 Sets (conjuntos)

Un Set en Dart es una colección no ordenada de elementos únicos. No permite duplicados, y el orden de los elementos no está garantizado.

Creación y características básicas

Puedes crear un Set usando llaves {} o el constructor Set(). Los elementos duplicados se ignoran automáticamente. 

void main() {
  Set<int> numeros = {1, 2, 3, 3, 4};
  print(numeros); // {1, 2, 3, 4} → sin duplicados
  numeros.add(5);
  numeros.remove(2);
  print(numeros); // {1, 3, 4, 5}
}

Métodos comunes de Set

Los Set ofrecen operaciones útiles como unión, intersección y diferencia. 

void main() {
  Set<String> a = {'manzana', 'plátano', 'naranja'};
  Set<String> b = {'plátano', 'kiwi', 'naranja'};

  print('Unión: \${a.union(b)}');            
  // {manzana, plátano, naranja, kiwi}

  print('Intersección: \${a.intersection(b)}'); 
  // {plátano, naranja}

  print('Diferencia (a - b): \${a.difference(b)}'); 
  // {manzana}
}

Verificación de elementos

Usa .contains() para comprobar si un elemento existe en el conjunto. 

Set<int> numeros = {10, 20, 30};
if (numeros.contains(20)) {
  print("20 está en el conjunto");
}

Iteración sobre un Set

Aunque el orden no está garantizado, puedes recorrer los elementos con un bucle for-in. 

Set<String> colores = {'rojo', 'verde', 'azul'};
for (String color in colores) {
  print("Color: \$color");
}

Notas importantes

  • Los Set son ideales cuando necesitas almacenar elementos únicos y no te importa el orden.
  • Si intentas crear un Set vacío con {}, Dart lo interpretará como un Map. Usa <Tipo>{} o Set<Tipo>() para evitar ambigüedades: Set<int> vacio = <int>{};.
  • Los elementos de un Set deben ser comparables (implementar == y hashCode correctamente).
  • A diferencia de las List, no puedes acceder a un elemento por índice en un Set.

8.3 Map (diccionarios)

Un Map en Dart almacena pares de clave-valor. Cada clave debe ser única, y se puede acceder al valor asociado mediante dicha clave. Los Map son ideales para representar datos estructurados como configuraciones, catálogos o registros.

Creación y acceso básico

Puedes crear un Map con llaves {} o con el constructor Map(). El acceso a un valor se hace con el operador [], que devuelve null si la clave no existe. 

void main() {
  Map diasSemana = {1: "lunes", 2: "Martes", 3: "Miércoles"};
  //acceso a elementos
  print(diasSemana[1]); // "lunes"

  // Añadir o actualizar
  diasSemana[4] = "Jueves";
  diasSemana[1] = "Lunes";

  // Recorrer el mapa
  diasSemana.forEach((num, dia) {
    print("$num → $dia");
  });
}

Métodos comunes

Los Map ofrecen múltiples métodos para manipular y consultar sus datos. 

Map<String, int> edades = {"Ana": 25, "Luis": 30};

// Verificar si existe una clave
if (edades.containsKey("Ana")) {
  print("Ana tiene \${edades["Ana"]} años");
}

// Verificar si existe un valor
if (edades.containsValue(30)) {
  print("Alguien tiene 30 años");
}

// Obtener todas las claves o valores
print("Claves: \${edades.keys}");     // (Ana, Luis)
print("Valores: \${edades.values}");   // (25, 30)

// Eliminar un par
edades.remove("Luis");
print(edades); // {Ana: 25}

Valores por defecto con putIfAbsent

Evita null al acceder a claves inexistentes usando métodos como putIfAbsent o el operador de nulabilidad. 

Map<String, int> puntuaciones = {"jugador1": 100};

// Si no existe, asigna un valor por defecto
int score = puntuaciones.putIfAbsent("jugador2", () => 0);
print(score); // 0
print(puntuaciones); // {jugador1: 100, jugador2: 0}

// O simplemente con operador ??
int score2 = puntuaciones["jugador3"] ?? 0;
print(score2); // 0 (sin modificar el mapa)

Mapas anidados

Es común usar Map dentro de otros Map para representar estructuras complejas. 

Map<String, Map<String, dynamic>> usuarios = {
  "user1": {
    "nombre": "Carlos",
    "edad": 28,
    "activo": true
  },
  "user2": {
    "nombre": "Lucía",
    "edad": 32,
    "activo": false
  }
};

print(usuarios["user1"]?["nombre"]); // "Carlos"

Notas importantes

  • Las claves en un Map deben ser objetos inmutables o que no cambien su hashCode (como String, int, etc.).
  • Al igual que con los Set, usar {} sin tipo puede interpretarse como Map o Set. Para evitar ambigüedad, especifica el tipo: Map<String, int> datos = {};.
  • El operador [] devuelve null si la clave no existe (en modo nul-safety, el tipo será V?).
  • Puedes usar entries para iterar sobre pares clave-valor como objetos MapEntry.

9. Nulabilidad (Null Safety)

Dart incluye Null Safety desde la versión 2.12, un sistema que evita errores en tiempo de ejecución al garantizar que no se acceda a valores null de forma accidental. Cada variable debe declararse explícitamente como nulable o no nulable.

Tipos no nulables vs. tipos nulables

Por defecto, los tipos en Dart no permiten null. Para permitirlo, añade ? al tipo. 

// No nulable → debe inicializarse
String nombre = "Ana";

// Nulable → puede ser null
String? apellido;

// ❌ Error de compilación:
// String ciudad; // No inicializada y no nulable → ¡no compila!
String? ciudad; // ✅ Válido

Operadores para trabajar con nulabilidad

Dart proporciona operadores seguros para manejar valores que podrían ser null. 

void main() {
  String? nombre;

  // Operador ?? → valor por defecto si es null
  print(nombre ?? "Desconocido"); // "Desconocido"

  // Asignar valor
  nombre = "Laura";

  // Operador ?. → invocación segura
  print(nombre?.toUpperCase()); // "LAURA"

  // Operador ! → afirmación de no nulidad (¡cuidado!)
  print(nombre!.length); // 5 (solo si estás seguro de que no es null)
}

Inicialización tardía con late

Si sabes que una variable no nulable se inicializará antes de usarse (pero no en la declaración), puedes usar la palabra clave late. 

late String configuracion;

void cargarConfiguracion() {
  configuracion = "modo-oscuro";
}

void main() {
  cargarConfiguracion();
  print(configuracion); // ✅ Válido gracias a "late"
}

Manejo seguro en funciones y parámetros

Los parámetros de funciones también pueden ser nulables, y debes manejarlos adecuadamente. 

void saludar(String? nombre) {
  if (nombre != null) {
    print("Hola, \$nombre");
  } else {
    print("Hola, invitado");
  }
  // O de forma más concisa:
  print("Bienvenido, \${nombre ?? "invitado"}");
}
🔑 Notas clave:
  • String → nunca puede ser null.
  • String? → puede contener una cadena o null.
  • ?? → devuelve el valor de la izquierda si no es null; si lo es, devuelve el de la derecha.
  • ?. → invoca un método o accede a una propiedad solo si el objeto no es null.
  • ! → fuerza el acceso asumiendo que no es null (usa con precaución).
  • late → para variables no nulables que se inicializan después de la declaración.

Null Safety no solo previene errores, sino que mejora la legibilidad y mantenibilidad del código al hacer explícitas las intenciones del desarrollador.

10. Clases y Programación Orientada a Objetos (POO)

Dart es un lenguaje orientado a objetos. Todo valor es un objeto, incluyendo números, funciones y null. Las clases definen la estructura y comportamiento de los objetos mediante propiedades (atributos) y métodos.

Definición básica de una clase

Una clase se define con la palabra clave class. Incluye campos (propiedades) y métodos (comportamientos). 

class Persona {
  String nombre;
  int edad;

  // Constructor
  Persona(this.nombre, this.edad);

  // Método
  void saludar() {
    print("Hola, soy \$nombre y tengo \$edad años.");
  }
}

void main() {
  var persona = Persona("Carlos", 30);
  persona.saludar(); // Hola, soy Carlos y tengo 30 años.
}

Constructores y propiedades

Dart permite una sintaxis concisa para asignar parámetros del constructor a propiedades usando this.. También puedes usar constructores con parámetros nombrados. 

class Coche {
  String marca;
  String? color; // opcional

  // Constructor con parámetros nombrados
  Coche({required this.marca, this.color});

  String get info => "Coche: \$marca \${color ?? 'sin color'}";
}

void main() {
  var coche1 = Coche(marca: "Toyota");
  var coche2 = Coche(marca: "Ford", color: "Rojo");
  print(coche1.info); // Coche: Toyota sin color
  print(coche2.info); // Coche: Ford Rojo
}

Herencia

Una clase puede heredar de otra usando extends. Dart no admite herencia múltiple, pero sí mixins (ver más abajo). 

class Animal {
  String nombre;
  Animal(this.nombre);

  void hacerSonido() {
    print("\$nombre hace un sonido.");
  }
}

class Perro extends Animal {
  Perro(String nombre) : super(nombre);

  @override
  void hacerSonido() {
    print("\$nombre dice: ¡Guau!");
  }
}

void main() {
  var perro = Perro("Firulais");
  perro.hacerSonido(); // Firulais dice: ¡Guau!
}

Métodos getter y setter

Puedes definir propiedades calculadas o controlar el acceso con get y set. 

class Rectangulo {
  double ancho, alto;
  Rectangulo(this.ancho, this.alto);

  // Getter calculado
  double get area => ancho * alto;

  // Setter personalizado
  set escalar(double factor) {
    ancho *= factor;
    alto *= factor;
  }
}

void main() {
  var r = Rectangulo(4, 5);
  print(r.area); // 20
  r.escalar = 2;
  print(r.area); // 80
}

Mixins: reutilización de código sin herencia

Los mixin permiten inyectar funcionalidad en múltiples clases, incluso si no están relacionadas. 

mixin Volador {
  void volar() {
    print("¡Estoy volando!");
  }
}

class Pajaro extends Animal with Volador {
  Pajaro(String nombre) : super(nombre);
}

void main() {
  var ave = Pajaro("Águila");
  ave.hacerSonido(); // Águila hace un sonido.
  ave.volar();       // ¡Estoy volando!
}

Notas importantes

  • Todas las clases en Dart heredan implícitamente de Object.
  • Usa @override para indicar que estás sobrescribiendo un método (mejora la legibilidad y evita errores).
  • Los constructores no se heredan, pero puedes llamar al constructor de la clase padre con super().
  • Dart no tiene modificadores de acceso como public o private; todo es público. Para simular privacidad, usa el guion bajo: _propiedad (solo visible dentro de la biblioteca).

11. Ejercicios Prácticos

A continuación, dos ejercicios que aplican los conceptos vistos: estructuras de control, funciones, colecciones, nulabilidad y programación orientada a objetos. Son ejemplos avanzados.

Ejercicio 1: Estadísticas de calificaciones

Escribe una función que reciba una lista de calificaciones (enteros entre 0 y 10) y devuelva un mapa con: "promedio", "aprobados" (≥5) y "maxima". Si la lista está vacía, devuelve valores por defecto seguros.

Solución:

// Función que analiza una lista de calificaciones numéricas (enteros)
// y devuelve un mapa con estadísticas resumidas.
Map analizarCalificaciones(List calificaciones) {
  // Caso especial: si la lista está vacía, devolvemos valores por defecto
  if (calificaciones.isEmpty) {
    return {
      "promedio": 0,   // No hay promedio real, así que 0
      "aprobados": 0,  // Ningún estudiante aprobado
      "maxima": 0      // No hay calificación máxima
    };
  }

  // Contamos cuántas calificaciones son >= 5 (consideradas "aprobadas")
  // - `where((n) => n >= 5)` filtra solo los elementos que cumplen la condición
  // - `.length` cuenta cuántos elementos quedaron después del filtro
  int aprobados = calificaciones.where((n) => n >= 5).length;

  // Calculamos el promedio:
  // - `reduce((a, b) => a + b)` suma todos los elementos de la lista
  // - Luego dividimos entre el número total de calificaciones
  double promedio = calificaciones.reduce((a, b) => a + b) / calificaciones.length;

  // Encontramos la calificación más alta:
  // - `reduce` compara cada par de elementos y se queda con el mayor
  // - `a > b ? a : b` es un operador ternario: si a > b, devuelve a; si no, b
  int maxima = calificaciones.reduce((a, b) => a > b ? a : b);

  // Devolvemos un mapa con las tres estadísticas calculadas
  return {
    "promedio": promedio,
    "aprobados": aprobados,
    "maxima": maxima
  };
}

void main() {
  List notas = [8, 7, 5, 9, 4];
  var resultado = analizarCalificaciones(notas);
  print(resultado);
}

Conceptos aplicados: listas, funciones, operadores de colección (where, reduce), nulabilidad, mapas.

Esta línea define una función en Dart. Vamos a desglosar cada parte para entender su significado y propósito.

La función analizarCalificaciones indica que devuelve un mapa (diccionario) donde:

  • Las claves son siempre de tipo String (ej. "promedio", "aprobados").
  • Los valores pueden ser de cualquier tipo (int, double, null, etc.), gracias a la palabra clave dynamic.

Se usa dynamic aquí porque el mapa mezcla tipos distintos: promedio es un double, aprobados es un int, y maxima puede ser int o null.

💡 NOTA:: Este código lo ha mejorado la IA después de mi codificación como humano donde he recorrido la lista para hacer los cálculos solicitados.
No te preocuopes si no hubieras sido capaz de hacerlo así. Yo tampoco. Conocer todas las funciones asociadas a los objetos de lenguaje es prácticamente imposible y más si estamos empezando. Lo importante es entender la lógica y el flujo del programa.

Alternativa más segura (opcional)

En lugar de usar Map<String, dynamic>, puedes crear una clase para mejorar la seguridad de tipos: 

class ReporteCalificaciones {
  final double promedio;
  final int aprobados;
  final int? maxima;
  ReporteCalificaciones(this.promedio, this.aprobados, this.maxima);
}

Esto evita el uso de dynamic y permite al compilador detectar errores antes de ejecutar el programa.

Ejercicio 2: Gestión de una biblioteca

Crea las clases Libro y Biblioteca. La biblioteca debe permitir: añadir libros, buscar por título (ignorando mayúsculas), y obtener una lista de libros disponibles. Usa encapsulamiento y métodos seguros.

Solución:

class Libro {
  final String titulo;
  final String autor;
  bool _disponible = true;

  Libro(this.titulo, this.autor);

  bool get disponible => _disponible;
  void prestar() => _disponible = false;
  void devolver() => _disponible = true;

  @override
  String toString() => "Libro: \$titulo por \$autor";
}

class Biblioteca {
  final List<Libro> _libros = [];

  void agregarLibro(Libro libro) {
    _libros.add(libro);
  }

  Libro? buscarPorTitulo(String titulo) {
    return _libros.firstWhere(
      (libro) => libro.titulo.toLowerCase() == titulo.toLowerCase(),
      orElse: () => null,
    );
  }

  List<Libro> get disponibles => _libros.where((l) => l.disponible).toList();
}

void main() {
  var biblio = Biblioteca();
  biblio.agregarLibro(Libro("Cien años de soledad", "García Márquez"));
  biblio.agregarLibro(Libro("1984", "Orwell"));

  var libro = biblio.buscarPorTitulo("1984");
  if (libro != null) libro.prestar();

  print("Disponibles: \${biblio.disponibles.length}");
  // Disponibles: 1
}

Conceptos aplicados: clases, encapsulamiento (propiedad privada con _), getters, métodos, colecciones, nulabilidad, firstWhere con orElse.
